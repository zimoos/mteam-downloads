# MTEAM downloads

Verified immutable MTEAM desktop downloads.

- [Apply for the Founding Beta](https://github.com/zimoos/mteam-downloads/issues/new?template=founding-beta.yml)
- Stable installers will appear under [Releases](https://github.com/zimoos/mteam-downloads/releases) after signing, notarization, and clean-device acceptance pass.

This repository distributes release artifacts and collects Founding Beta applications. MTEAM source code is maintained privately.
